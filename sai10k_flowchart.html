SpliceAI-10k calculator (SAI-10k-calc) algorithm pseudo-code

Pseudo-code

The three outer blocks — splice site loss, splice site gain, and cryptic splice site activation — evaluate independently, so a single variant can emit aberrations from more than one. Click a ▶ to collapse or expand that block. 

# ---------------------------------------------------------------------
# Definitions
# ---------------------------------------------------------------------
#   AG, AL, DG, DL            shorthand for Acceptor Gain, Acceptor Loss,
#                             Donor Gain, Donor Loss
#
#   DS_AG, DS_AL, DS_DG,      delta scores from SpliceAI for each of the four
#   DS_DL                     splice-altering events (probability the variant
#                             gains/loses an acceptor or donor site)
#
#   DS_AG_ALT, DS_AL_ALT      ALT-allele *acceptor* probabilities at the predicted
#                             acceptor-gain position (DS_AG_ALT, at variant_pos + DP_AG)
#                             and at the predicted acceptor-loss position
#                             (DS_AL_ALT, at variant_pos + DP_AL)
#   DS_DG_ALT, DS_DL_ALT      ALT-allele *donor* probabilities at the analogous
#                             donor-gain and donor-loss positions
#                             (SpliceAI "refalt" output)
#
#   DP_AG, DP_AL, DP_DG,      delta positions (bp offset from the variant) of
#   DP_DL                     the predicted acceptor/donor gain/loss sites
#
#   GEO_AG, GEO_AL, GEO_DG,   1-based genomic positions of the predicted sites,
#   GEO_DL                    computed as GEO_* = variant_pos + DP_*
#   GEO_NA, GEO_ND            1-based genomic positions of the native acceptor and
#                             native donor of the associated exon
#                             (GEO_NA = variant_pos + DP_NA, similarly for GEO_ND)
#
#   DP_NA, DP_ND              delta positions of the native acceptor and
#                             native donor of the associated exon.
#                             "Associated exon" = the containing exon when the
#                             variant is exonic, or the closer of the two
#                             flanking exons when the variant is intronic.
#
#   native_exon_size          size (bp) of the associated native exon
#   partial_size              size (bp) of the shift from a native splice site to a
#                             predicted cryptic site; positive → partial exon
#                             deletion, negative → partial intron retention
#
#   DG_native_match           TRUE when GEO_DG == native donor of the
#                             associated exon  (i.e. DP_DG == DP_ND)
#   DG_acceptor_match         TRUE when GEO_AG == native acceptor of the
#                             associated exon  (i.e. DP_AG == DP_NA).
#                             NOTE: the name is from spliceAI_parser.R line 930
#                             and is misleading — the "DG" prefix suggests this
#                             tests a donor-gain position, but the flag actually
#                             tests the acceptor-gain position against the
#                             associated exon's native acceptor.
#
#   strand                    +1 for forward-strand genes, −1 for reverse
#   d_from_exon               distance from variant to nearest exon-intron
#                             junction (0 if the variant is exonic)
# ---------------------------------------------------------------------

function compute_predictions(variant, transcript):
    if max(DS_AG, DS_AL, DS_DG, DS_DL) < 0.02:
        return []                      # no splicing aberration predicted

    locate variant in exon or intron
    compute d_from_exon (distance to nearest exon-intron junction; 0 if exonic)
    identify associated exon and its native acceptor (DP_NA) and native donor (DP_ND)
    aberrations = []
# Splice site loss (AL, DL) 
    if min(DS_AL, DS_DL) ≥ 0.02 and max(DS_AL, DS_DL) ≥ 0.2
       and d_from_exon ≤ 50:
        if DP_AL · strand < DP_DL · strand:   # ensures acceptor lies 5' of donor in transcript order
            aberrations.append("(Multi)exon skipping")      # the skipped exons are identified later, during annotation
        else:
            aberrations.append("Whole intron retention")
        if min(DS_AL, DS_DL) < 0.2:
            mark the emitted aberration as "Potential"
# Splice site gain (AG, DG) 
    if min(DS_AG, DS_DG) ≥ 0.02 and max(DS_AG, DS_DG) ≥ 0.2   # paper text says 0.05 for DS_AGDG_MAX; spliceAI_parser.R line 28 and this implementation use 0.2
       and DP_AG · strand < DP_DG · strand:
        gained_exon_size = (DP_DG − DP_AG) · strand + 1
        if 25 ≤ gained_exon_size ≤ 500
           and d_from_exon > 50
           and AG and DG share the same host intron
           and AG and DG are both > 51 bp from each flanking exon
               boundary of that host intron:
            aberrations.append("Pseudoexon activation")
            # This check mirrors spliceAI_parser.R lines 211-214 exactly: R uses
            # `intronStart + 50 < AGpos` where intronStart is the first intronic base,
            # which translates to "AG > 51 bp from the flanking exon boundary" (and
            # symmetrically for DG). This implementation uses the same effective
            # threshold (> 51 bp).
        elif gained_exon_size == native_exon_size
             and DP_AG == DP_NA and DP_DG == DP_ND:
            aberrations.append("Increased exon inclusion")
# Cryptic splice site activation (acceptor or donor) 
    if max(DS_AG, DS_DG) > 0 and the variant is locatable within the transcript
            (i.e. the variant falls inside an exon or intron of the transcript,
            so the associated exon and its native acceptor/donor are known):
        acceptor_diff = DS_AG_ALT − DS_AL_ALT
        donor_diff    = DS_DG_ALT − DS_DL_ALT
# cryptic acceptor 
        if (  # --- activation criteria: the acceptor gain is a real signal ---
              (DS_AG < 0.2 and DS_AL > 0.1
               and DS_AG_ALT ≥ 0.9 and acceptor_diff ≥ 0.2)   # weak-DS arm
           or (DS_AG ≥ 0.2 and acceptor_diff > −0.2)             # strong-DS arm
           )
           and (  # --- side-selection: the acceptor is the cryptic side ---
                  (DG_native_match and not DG_acceptor_match)          # donor at native, acceptor cryptic
               or (not DG_native_match and not DG_acceptor_match
                   and DS_AG > DS_DG)                                # neither at native; higher-DS wins (tie → neither fires)
              )
           and GEO_AG lies past the biologically-upstream exon's donor   # orientation
               # Exon boundaries below are given in ascending-genomic-coordinate terms;
               # on − strand, "biologically upstream" = genomically downstream, so R's
               # biologically-ordered `prev_eStart` (spliceAI_parser.R line 953) corresponds
               # to what we call `next_exon_start` here.
               (+ strand: prev_exon_end < GEO_AG;
                − strand: GEO_AG < next_exon_start;
                auto-passes if the associated exon is the first in the transcript):

            partial_size = (DP_AG − DP_NA) · strand
            # sign convention: positive → cryptic acceptor is inside the native exon (deletion);
            #                  negative → cryptic acceptor is in the upstream intron (retention)
            if 0 < partial_size < native_exon_size and d_from_exon ≤ 50:
                aberrations.append("Partial exon deletion")
                # NOTE: the < native_exon_size upper bound is not in spliceAI_parser.R (line 998);
                # this implementation suppresses shifts that span past the opposite end.
            elif −250 ≤ partial_size < 0 and d_from_exon ≤ 250:
                aberrations.append("Partial intron retention")
# cryptic donor 
        if (  # --- activation criteria: the donor gain is a real signal ---
              (DS_DG < 0.2 and DS_DL > 0.1
               and DS_DG_ALT ≥ 0.9 and donor_diff ≥ 0.2)      # weak-DS arm
           or (DS_DG ≥ 0.2 and donor_diff > −0.2)                # strong-DS arm
           )
           and (  # --- side-selection: the donor is the cryptic side ---
                  (DG_acceptor_match and not DG_native_match)          # acceptor at native, donor cryptic
               or (not DG_native_match and not DG_acceptor_match
                   and DS_AG < DS_DG)                                # neither at native; higher-DS wins (tie → neither fires)
              )
           and GEO_DG lies before the biologically-downstream exon's acceptor   # orientation
               # Exon boundaries below are given in ascending-genomic-coordinate terms;
               # on − strand, "biologically downstream" = genomically upstream.
               (+ strand: GEO_DG < next_exon_start;
                − strand: prev_exon_end < GEO_DG;
                auto-passes if the associated exon is the last in the transcript):

            partial_size = (DP_ND − DP_DG) · strand
            # sign convention: positive → cryptic donor is inside the native exon (deletion);
            #                  negative → cryptic donor is in the downstream intron (retention)
            if 0 < partial_size < native_exon_size and d_from_exon ≤ 50:
                aberrations.append("Partial exon deletion")
                # NOTE: the < native_exon_size upper bound is not in spliceAI_parser.R (line 998);
                # this implementation suppresses shifts that span past the opposite end.
            elif −250 ≤ partial_size < 0 and d_from_exon ≤ 250:
                aberrations.append("Partial intron retention")

    # -----------------------------------------------------------------
    # Annotation phase: compute size, CDS overlap, and reading-frame
    # effect for each emitted aberration.
    # -----------------------------------------------------------------
    # INTENTIONAL DIVERGENCE FROM spliceAI_parser.R: the frameshift test
    # below is computed from the CDS-overlapping portion of the affected
    # segment (cds_size), NOT from the full genomic size. The reference
    # parser uses full size (e.g. full skipped-exon size for exon_skipping),
    # which is incorrect when an affected segment straddles a UTR/CDS
    # boundary — only the coding bases affect the reading frame.
    # -----------------------------------------------------------------
    for each aberration:

        if aberration is "(Multi)exon skipping":
            # Match SpliceAI's predicted loss positions to native exon
            # boundaries:
            #     GEO_AL  (expected at an exon's acceptor)
            #     GEO_DL  (expected at an exon's donor)
            acc_candidates = all exons whose acceptor coincides with GEO_AL
            don_candidates = all exons whose donor    coincides with GEO_DL
            if acc_candidates and don_candidates:
                # Pick the (acc, don) pair with the smallest index span.
                # When acc == don this is single-exon skipping; otherwise
                # skip all exons between them inclusive (multi-exon skipping).
                (acc_exon, don_exon) = pair with min |acc_index − don_index|
                skipped_exons = all exons from min(acc_exon, don_exon)
                                through max(acc_exon, don_exon) inclusive
            else:
                # Fallback (this implementation only; spliceAI_parser.R (line 229)
                # leaves the lost-exon list as NA). If the variant is exonic
                # AND at least one of GEO_AL / GEO_DL matches the affected
                # exon's own boundary, treat that single exon as skipped.
                # Otherwise leave skipped-exon list unknown.
                skipped_exons = affected exon, or unknown
            size = sum of skipped_exons' sizes
            cds_size = sum of CDS-overlapping bases within each skipped exon
            affected_segment_desc = "skipped exons"

        elif aberration is "Whole intron retention":
            size = |GEO_AL − GEO_DL| − 1   # −1 excludes the two exon-boundary bases (GEO_AL, GEO_DL)
            cds_size = CDS-overlapping bases in (min(GEO_AL,GEO_DL)+1 .. max−1)

        elif aberration is "Pseudoexon activation":
            size = |GEO_DG − GEO_AG| + 1
            cds_size = CDS-overlapping bases in (min(GEO_AG,GEO_DG) .. max)

        elif aberration is "Increased exon inclusion":
            size = native_exon_size
            # Special case: frameshift is not computed for this type
            # (sai10k_predictions.py line 765 sets frameshift = None).
            # Label is "coding" / "non-coding" / "unknown" only —
            # not "frameshift" / "in-frame".
            affects_coding = does the native exon overlap the CDS range?
            label as "coding" / "non-coding" / "unknown" accordingly
            # example output: "Increased exon inclusion (342bp) - coding"
            continue

        elif aberration is "Partial exon deletion" or "Partial intron retention":
            size = |partial_size|
            # Affected range spans from the native site toward the cryptic site,
            # excluding the new splice boundary:
            #   partial_exon_deletion   → exclude GEO_AG or GEO_DG (new boundary)
            #   partial_intron_retention → exclude GEO_NA or GEO_ND (native boundary)
            cds_size = CDS-overlapping bases in that range   # length == size by construction

        # Coding-consequence rule.  Applies to exon_skipping and partial_exon_deletion;
        # partial_intron_retention cannot delete the start/stop codon (the native site
        # itself is not retained), so start_lost / stop_lost are always False there.
        affects_coding = (cds_size > 0)
        start_lost = affected_segment contains cds_start (start codon position)
        stop_lost  = affected_segment contains cds_end   (stop  codon position)

        if not affects_coding:
            status = "non-coding"
        elif start_lost:
            status = "start codon lost"   # translation must re-initiate elsewhere
        elif stop_lost:
            status = "stop codon lost"    # read-through / extended protein
        elif (cds_size mod 3) != 0:
            status = "frameshift"
        else:
            status = "in-frame"

        if affects_coding:
            label as "(<cds_size>bp coding seq.) - <status>"
        else:
            label as "(<size>bp) - non-coding"
        # For non-coding transcripts (no CDS defined), cds_size is always 0,
        # so affects_coding is False and frameshift is None regardless of size.

    report the overall (per-variant) max Δ score across all four events,
        its splice-site type (acceptor/donor loss or gain), and a confidence label
        (≥ 0.8 high, ≥ 0.5 moderate, < 0.5 low)
    return aberrations
